# 训练室

> [!WARNING]
> 本项目目前仅发布测试版，尚未发布任何正式版。包括历史上的 `v1.0.9`、`v1.0.10` 以及当前迭代在内，所有版本均应视为测试版本，可能存在缺陷或不兼容变更。

**[查看并下载最新测试版（GitHub Releases）](https://github.com/WangXiangpu0916/Arknights-Training-Room/releases)**

Windows 10/11 本地桌面测试应用。读取森空岛的真实仓库、持有干员、精英化、模组和技能专精状态，按加工站的确定配方进行库存扣除模拟，直接给出当前可行的专精、精英化与模组升级。运行时不使用 LLM、Agent、AI API 或 AI Token。

## 已实现

- 森空岛 App 扫码登录、绑定角色选择、手动刷新与可选启动刷新
- 仓库、精英阶段、技能 Rank、每技能 M0/M1/M2/M3 与模组等级同步
- 精英化规划：支持筛选与 E0→E2 连续规划，累计经验、升级/晋升龙门币及材料并逐阶段扣减库存
- 模组规划：支持筛选、同一干员多个模组与 Lv.0→Lv.3 连续规划，显示官方模组类型并校验精二、等级和完整材料门槛
- `M2→M3 > M1→M2 > M0→M1` 单阶段独立规划
- 仅展示跨度至少两级的连续专精
- 多层递归、共享原料、整数批次、多产物和循环防护
- 无限材料的正式状态、合成链传播及结果依赖标记
- 首页筛选、列表式干员档案、固定仓库详情栏、材料用途/描述、多级递归可合成数量及三类规划详情
- 跟随系统、黑色和浅色三态主题
- 独立游戏资源版本、完整数据 / metadata / 图片快照、兼容性校验与失败回滚
- Windows DPAPI 凭据加密、退出账号、脱敏轮转日志
- NSIS 安装包与 portable 单文件构建

## 使用

1. 从 `release` 目录运行测试版安装包或 portable 版本。
2. 首次启动点击“使用森空岛 App 扫码连接”。
3. 在森空岛 App 中确认登录，选择绑定的《明日方舟》角色。
4. 同步完成后可分别查看当前可行的专精、精英化与模组升级。
5. 活动无限池材料在“仓库”页开启；真实库存数字始终保持不变。

设置页可以独立检查并更新游戏资源、切换主题、清理账号缓存或删除本地认证。资源更新无需更新应用版本。[资源架构与发布流程](docs/RESOURCE_UPDATES.md)

## 本地数据与安全

数据默认保存在 `%APPDATA%/arknights-training-room`：

- `credentials.bin`：Electron `safeStorage` 加密；Windows 上使用 DPAPI
- `account-cache.json`：最近一次成功的账号快照，不含登录凭据
- `settings.json`：无限材料、主题、选中 UID 和自动刷新开关
- `game-data/`：最近一次成功的完整游戏资源快照（数据、metadata、图片与 manifest）
- `game-data.backup/`：上一份可用快照；未提交事务在启动时自动恢复
- `app.log` / `app.log.1`：最大约 1 MB，敏感长字符串会被替换为 `[REDACTED]`

“清理账号缓存”不删除凭据；“退出 / 删除认证”只删除加密凭据。规划始终使用账号快照的副本，不会修改真实仓库缓存。

## 计算保证

每次可行性判断都复制真实仓库。加工会按整数批次递归扣除输入，确定产物才入库，随机副产物完全忽略；任何未知材料、缺失配方、无效产量或循环依赖都会保守地判为不可行。单阶段候选各自从同一快照开始，连续模式则把上一阶段的剩余库存交给下一阶段。

无限材料用集合状态表示，不用大数字替代。某产物只有在其本身被设为无限，或配方的每一种输入都可由无限链得到时，才会传播为无限。

## 已知限制

- 森空岛接口是非公开接口，没有公开 SLA、固定 Token 生命周期或频率额度；应用只在用户刷新或明确启用启动刷新时访问，并按返回错误码刷新签名 Token/凭据。
- 当前静态名称与账号接口针对国服简中数据。
- 未登录时无法端到端验证某个真实账号；数据契约基于 2026-08 仍维护的实现，接口改变时会显示错误并保留旧缓存，不会给出可能错误的新候选。
- 新增干员、技能、材料、模组、metadata 和图片通过完整资源包更新；不兼容 schema 会提示升级应用并保留旧资源。
- 模组规划可以校验森空岛已返回的阶段、等级、当前模组等级与材料；游戏内模组任务和信赖条件不在当前接口数据中，首次开启前仍须在游戏内确认。
- 森空岛培养快照当前未稳定提供干员本级已积累经验；字段缺失时精英化规划按本级 0 经验保守计算，若接口未来返回该字段则自动扣除已有经验。
- GitHub 仓库为私有时，未认证的 `electron-updater` 无法读取 Releases；应用会给出简短错误并写入完整本地日志。要启用应用内自动更新，需要将发布仓库设为公开或迁移到公开更新源，不能把私人访问令牌写进客户端。
- 当前构建没有商业 Authenticode 证书，Windows SmartScreen 可能在首次运行时显示“未知发布者”；可核对下方交付哈希后选择继续运行。
